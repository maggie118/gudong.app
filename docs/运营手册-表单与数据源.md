# Gudong 运营手册：表单与数据源（B+C 方案）

更新：2026-11-13

## 一、你在哪里录入资料

主数据表（唯一入口）：
https://docs.google.com/spreadsheets/d/1bXToBUVn9T1R6dcImOvQAlh2arXdDx4n1mtoYCDxV3U/edit

页签（从左到右）：

| 页签 | 内容 | 谁填 |
|---|---|---|
| 第 2 张表单回复 | 卖家自己提交的「藏品提交」 | 卖家填，你审 |
| 第 1 张表单回复 | 卖家自己提交的「卖家入驻申请」 | 卖家填，你审 |
| 旧空表 | 早期空表，可忽略 | — |
| sellers | 正式卖家档案（9 家） | 你审核后手动搬进来 |
| items | 正式藏品表（30 件） | 你审核后手动搬进来 |
| 藏品提交 | 空表，留作备用 | — |

网站的数据源就是这个表格的 `items` 与 `sellers` 两个页签：`scripts/sheets-source.js` 已默认指向它，构建时按页签名拉公开 CSV。Airtable 只作应急。

## 二、两个对外的 Google 表单（已发布）

1. 卖家入驻申请 / Seller Application
   https://docs.google.com/forms/d/e/1FAIpQLSeu3dk4sJ8dmJW1DQh-KC2dcm7GzN4zj2TnQGieo6S1USblrw/viewform
   题：展馆名（中文/英文）、邮箱、卖家编号（首次可空）、从业年份、WhatsApp、藏馆简介、是否申请私家藏馆、图片或资料链接。
   必填：中文名、英文名、邮箱、从业年份、藏馆简介。

2. 藏品提交 / Item Submission
   https://docs.google.com/forms/d/e/1FAIpQLSeQOE9oBw3bleAwFcUZMA2IhiNrO3Ax8p7Iat1z8sgL4XZdiA/viewform
   题：藏馆名/卖家编号、item_id、中英文名、品类、年代、尺寸、重量、价格方式、价格、图片文件名或 Drive 链接、是否申请「今日发现」曝光、品相说明。
   必填：卖家编号、中文名称、年代、图片文件名或链接、是否申请曝光。

站点上的入口（已上线，构建自动读取这两个链接）：
- `/` 首页卖家区：「提交入驻申请」按钮 → 入驻表单
- `/pricing` 藏家服务页：申请新批次席位按钮 → 入驻表单；专业上架弹窗里的「提交表单」→ 藏品提交表单

注意：Google 表单不能上传文件。图片由卖家按 `assets/images/<卖家目录>/文件名.jpg` 命名，或在表单里粘 Drive 链接；也可以让他先在 WhatsApp 发原图。

## 三、审核与上架流程

1. 卖家填「入驻申请」→ 出现在「第 1 张表单回复」。
2. 你审核通过后，把这一行手工搬到 `sellers` 页签，补齐字段，并在 `founding_no` 填编号（如 001）。`gallery` 打 TRUE 才建私家藏馆页；填了 `gallery_started_at` 就自动进入 7 天「今日发现」免费曝光窗口。
3. 卖家填「藏品提交」→ 出现在「第 2 张表单回复」。审核通过后搬到 `items` 页签，图片按文件名放进仓库对应目录，不改器物真实颜色与形状。
4. 曝光：`is_today_finds` 勾 TRUE 且无到期日 = 样板/手动曝光位；私家藏馆开馆 7 天窗口内自动全店入池。

## 四、改完表格后如何让网站生效

网站是静态站，表格改动要重新构建才会体现。改完表直接告诉我「发布」，我执行：
`npm run build` → git commit → push origin HEAD:main → Vercel Deploy Hook → 约 3 分钟线上生效。

自己也能做：Vercel 项目 `gudong-app` 右上角 Redeploy，或本地跑上面的命令。

## 五、常见问题

- 表格必须保持「知道链接的任何人（可查看）」，否则构建拿不到 CSV，会退回仓库里的 `data/items.csv`、`data/sellers.csv`。
- 页签名不要改：`items` / `sellers` 是构建的取数依据。
- `item_id` 是页面地址的一部分（`/items/item-lim-05`），一旦上架就不要再改。
- 回复页签里出现多余列，是旧表单残留，别删主表列，重新提交新表单即可。
