选一个品类，回答 9–13 个问题。结果给出目视倾向、矛盾组合说明什么、按顺序怎么核实、可对照的参考数据，以及成交前该写进合同的条款。 Pick a category and answer 9-13 questions. You get a visual lean, what the pattern suggests, an ordered verification list, reference data to compare against, and terms to put in writing.
先读这一句Read this first 这是排除式自查：只帮你发现明显不对劲的地方，不给真伪结论。任何一项命中都不足以定案，任何一项未命中也不代表是真品。 This is an elimination-style self-check: it helps you spot obvious warning signs, not reach a verdict. One hit never settles a case; one clean answer never proves authenticity.
