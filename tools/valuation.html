简易估值参考 Market Valuation Reference
买卖前先建立合理的心理价位。按品类、年代、完整度与工艺级别选择，得出参考市场区间与行情趋势。 Set a realistic price expectation before buying or selling. Pick category, era, condition and craft level to see a reference range and trend.
使用范围提示Scope notice 本工具基于品类基准价 × 年代 / 完整度 / 工艺系数的简化模型，只帮你建立心理预期区间。同一器物因来源、品相、市场时点差异巨大，不能代替专业估价或鉴定。 This tool uses a simplified category base × era / condition / craft factor model to set a psychological price band. Real prices vary hugely by provenance, condition and timing; it cannot replace a professional appraisal.
